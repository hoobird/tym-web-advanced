# Movie Gallery Project

This is a **Movie Gallery** project created for the **Web Development Intermediate** module.

---

## 📖 Project Overview

The Movie Gallery is a React web application built with **Material UI (MUI)**. It showcases a gallery of movies featuring details such as movie posters, titles, release years, descriptions, ratings, and video trailers loaded from a local JSON file (`src/data/movies.json`).

---

## 🚀 Getting Started

Follow these steps to set up and run the project locally on your machine:

### 1. Install Dependencies

When you first clone or download the repository, you **must** install all the necessary dependencies before running the app. 

Open your terminal, make sure you are in the `movie-gallery` folder, and run:

```bash
npm i
```
*(or `npm install`)*

---

### 2. Start the Project

To start the development server, run:

```bash
npm start
```

This will start the local development server and automatically open [http://localhost:3000](http://localhost:3000) in your web browser. The app will automatically reload whenever you make changes to the source code.

---

### 3. Stop the Project

To stop the running development server:
1. Focus on your terminal window where the server is running.
2. Press **`Ctrl + C`** (or **`Cmd + C`** on macOS).
3. If prompted with `Terminate batch job (Y/N)?`, type `Y` and press Enter.

---

## 🛠️ Tech Stack

- **React** (v19)
- **Material UI (MUI)** for UI components and styling
- **React Player** for embedding trailers
